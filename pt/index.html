GBFR Save Analytics — Editor e Análise de Save de Granblue Fantasy: Relink

Ferramenta gratuita para análise e correção de dados de save para Granblue Fantasy: Relink (PC). Inspecione o progresso dos seus personagens, recalcule hashes XXHash64, gerencie sigilos e compare backups — tudo 100% no seu navegador.

Recursos Principais

  • Verificação e Correção de Hash XXHash64: Recálculo automático de checksum ao baixar o save para que o jogo reconheça as modificações sem erros.
  • Progresso dos Personagens: Consulte nível, MSP, EXP, armas equipadas e composição do grupo.
  • Análise de Sigilos e Inventário: Distribuição de sigilos por nível, materiais abundantes e itens em falta.
  • Comparador de Saves: Compare diferenças de Rupies, itens e progresso entre o save atual e backups.
  • Privacidade Total e Seguro: Nenhum dado é enviado para a nuvem. O processamento é totalmente local na máquina.

Perguntas Frequentes (FAQ)

Meu save é enviado para algum servidor?

Não. Toda a leitura, edição e cálculo de hashes acontecem diretamente no seu navegador localmente.

Onde encontro o arquivo SaveData1.dat?

No Windows (Steam), o arquivo fica na pasta %LOCALAPPDATA%\GBFR\Saved\SaveGames.

Como recuperar ou validar um save com erro no jogo?

Arraste o SaveData1.dat para a ferramenta, confira o selo de integridade e clique em "Baixar save corrigido" para atualizar o hash XXHash64.
